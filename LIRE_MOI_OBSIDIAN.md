# Passation Obsidian

Archive contenant les coffres Obsidian trouves sur le PC.

## Coffres inclus

- `TARS RAG`
- `galaxie_societe`
- `galaxie_societe/Société` : coffre Obsidian imbrique, inclus dans `galaxie_societe`
- `maroc_doleances_vault`
- `medias_maroc_vault`
- `TARS Thinking`

## Installation sur l'autre PC

1. Copier le zip sur l'autre PC.
2. Extraire tout le zip dans un dossier local, par exemple `Documents/Obsidian`.
3. Installer Obsidian si necessaire.
4. Dans Obsidian, cliquer sur `Open folder as vault`.
5. Selectionner un des dossiers de coffre ci-dessus.
6. Repeter pour les autres coffres a ouvrir.

## Important

Les dossiers `.obsidian` sont inclus. Ils contiennent les reglages locaux, themes, plugins et espaces de travail de chaque coffre.

Si Obsidian demande d'activer les plugins communautaires, verifier les plugins avant activation sur le nouveau PC.
